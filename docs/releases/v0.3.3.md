## 中文

- macOS 版本新增正式 Developer ID 签名和 Apple 公证。
- Windows ARM64 和 x64 版本改为 ZIP 下载，减小下载体积；解压后运行 ChirpOS.exe，无需安装 .NET。
- 本版本没有修改鸟类行为和应用功能。Windows 版本仍未使用发布者证书签名。

### 下载

- macOS Apple Silicon：ChirpOS-0.3.3-macOS-arm64.zip，macOS 13+。
- Windows ARM64：ChirpOS-0.3.3-win-arm64.zip。
- Windows Intel / AMD x64：ChirpOS-0.3.3-win-x64.zip。

更新前请退出旧版本，设置会保留。

验证：macOS 41 项核心测试及 13 项桌面集成检查通过；Windows 35 项核心检查通过。两个 Windows ZIP 已校验，尚未在 Windows 桌面实测。

## English

- macOS builds are now Developer ID-signed and notarized by Apple.
- Windows ARM64 and x64 downloads are now ZIP archives to reduce download size.
  Extract the archive and run ChirpOS.exe; no separate .NET installation is required.
- No changes to bird behavior or application features. Windows binaries remain unsigned.

Quit the previous version before updating; preferences are preserved.

Validation: 41 macOS core tests, 13 desktop integration checks, and 35 Windows core checks passed. Both Windows ZIP archives were verified; Windows desktop testing was not performed.
