## 中文

啾啾现已支持 Windows，保留七种像素鸟的飞行、着陆与习性动画，以及窗口顶沿停留、拖动跟随、快速移动受惊和随机鸟群。

- 新增 Windows 原生托盘菜单、中英文切换、登录启动和概率滑块／输入／锁定。
- 新增「体型与动作」页：体长、振翅频率、飞速、最短和最长停留时间；保存后对新飞入的小鸟生效。
- 修正透明拖动辅助窗口被误当作实心遮挡物的问题；飞行期间仍在抵达后才切换目的窗口层级。
- 项目拆分为 macOS、Windows 与共用素材目录，原有 macOS 构建入口不变。

**下载后直接运行，无需解压或安装 .NET：**
- `ChirpOS-0.3.1-win-arm64.exe`：Windows 11 ARM64，包含 Apple Silicon 上的 UTM。
- `ChirpOS-0.3.1-win-x64.exe`：Intel / AMD 64 位 Windows 10/11。

更新前请从托盘退出旧版。概率、锁定和其他偏好保存在用户目录，更新程序会保留。程序尚未使用 Windows 发布者证书签名。

验证：28 项 Windows 核心检查通过；用户已在 UTM Windows ARM64 中确认本版运行正常。x64 已构建，未在 x64 Windows 桌面上实测。macOS 重构后 38 项核心测试、21 项设置检查通过。

本次发布提供 Windows 程序。Mac 用户请继续使用 [macOS v0.2.0](https://github.com/billtt/chirp-os/releases/tag/v0.2.0)。

## English

ChirpOS now supports Windows with seven pixel-art birds, species-specific animations, window-edge perching, drag following/startle behavior, and a changing population.

- Native Windows tray controls, language switching, launch at login, and probability sliders, numeric inputs, and locks.
- Size & behavior settings for body length, wingbeat rate, speed, and perch duration; saved settings apply to new arrivals.
- Transparent drag helper windows no longer act as solid occluders. Destination depth still changes only on arrival.
- Separate macOS and Windows source trees with shared artwork; existing macOS build entry points remain available.

Run the appropriate `.exe` directly; no extraction or separate .NET installation is needed. Choose ARM64 for Windows 11 ARM/UTM, or x64 for Intel/AMD Windows 10/11. Quit the previous version from the tray before updating. User settings are preserved. The executable is not publisher-signed.

Validation: 28 Windows core checks passed; the user confirmed this version works in UTM Windows ARM64. x64 is built but has not been desktop-tested. The macOS refactor passed 38 core tests and 21 settings checks.

This release contains Windows executables. Mac users can continue using [macOS v0.2.0](https://github.com/billtt/chirp-os/releases/tag/v0.2.0).
