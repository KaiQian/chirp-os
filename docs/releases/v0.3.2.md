## 中文

修复小鸟在被部分遮挡的窗口顶沿扎堆的问题，macOS 和 Windows 使用相同的落点选择规则：

- 在整段可见边沿上连续随机选择落点，空间更宽的边沿有更多机会被选中。
- 避开已停留的小鸟，以及其他小鸟正在飞往的落点。
- 没有足够空间时寻找其他窗口，保持着陆位置完整可见。

### 下载

- **macOS Apple Silicon**：`ChirpOS-0.3.2-macOS-arm64.zip`，解压后打开 `ChirpOS.app`，要求 macOS 13+。
- **Windows ARM64 / UTM**：`ChirpOS-0.3.2-win-arm64.exe`。
- **Windows Intel / AMD x64**：`ChirpOS-0.3.2-win-x64.exe`。

Windows 程序可直接运行，无需解压或安装 .NET。更新前请退出旧版本，设置会保留。macOS 应用尚未公证，Windows 程序未使用发布者证书签名。

验证：Mac 41 项核心测试及 13 项窗口集成检查、Windows 35 项核心检查通过。用户已确认 Mac 中落点扎堆问题修复。Windows 本轮落点修复已构建并通过核心检查，尚未完成桌面实测。

## English

Fixes birds crowding into the same spot on partially obscured window edges on macOS and Windows.

- Samples continuously across visible edges, with selection proportional to available space.
- Reserves space for perched birds and birds already approaching a destination.
- Chooses another window when space is insufficient, while keeping the entire landing sprite visible.

This single release includes a macOS Apple Silicon ZIP (macOS 13+) and standalone Windows ARM64 and x64 executables. Quit the previous version before updating; preferences are preserved. No separate .NET installation is required. The Mac app is not notarized and the Windows binaries are not publisher-signed.

Validation: 41 macOS core tests, 13 window integration checks, and 35 Windows core checks passed. The user confirmed the crowding fix on Mac. The Windows change is built and core-tested but has not yet been desktop-tested.
